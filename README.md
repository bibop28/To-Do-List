# 🔥 To Do List

To Do List is a simple Python console-based application designed to help users keep track of their tasks. It provides a straightforward way to manage tasks from the terminal, making it perfect for quick task management. With its easy-to-use interface, users can efficiently add, view, and mark tasks as done.



---
## ✨ Key Features
* ✅ Add new tasks
* 📋 View all tasks with status
* ✔️ Mark tasks as done
* 🗑️ Display a message when the list is empty
* 🖥️ Simple console interface

---
## 🧭 Simple Workflow
1. Open the To Do List application
2. Add new tasks by typing them in and confirming
3. View all tasks with their current status
4. Mark tasks as done when completed
5. Review the updated task list

---
## 🎯 Purpose
The purpose of To Do List is to provide a simple, console-based task management system that allows users to easily add, view, and mark tasks as done, helping them stay organized and focused.

---
## 🧩 Installation & Usage
```bash
git clone https://github.com/bibop28/To-Do-List
cd To-Do-List
```
To run the application, navigate to the project directory and execute the Python script. The application will be accessible from the terminal, and users can interact with it by following the on-screen instructions.

## 🛠️ Tech Stack
To Do List is built using Python, leveraging its simplicity and ease of use to create a straightforward console-based application. The tech stack is minimalistic, focusing on providing a functional and user-friendly task management experience.
